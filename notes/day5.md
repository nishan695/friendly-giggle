1. HTML Document Structure
 I learned about the main elements usedd to structure an HTML 
 document:

 - <html> root of the html document
 - <head> contains information about the webpage
 - <meta> provides metadat about the document
 - <title> defines the title shown in the browser tab
 - <link> connects external resources such as css files
 - <body> contains the visible content of the web page 
 - <header> represents the introductory header section 
 - <footer> represents the footer section 

## connecting css with HTML 
> I learned how to attach a css file to an
HTML document.

Example:
html
<head>
<link rel="stylesheet"href="style.css">
</head>

This allows the style written in style.css to be 
applied to the HTML page

2. Flexbox
i was introduced to CSS flexbox

it is used to arrange and align elements
inside a container.

some basic concepts i learned:
display:flex
arranging elements in rows and columns 
Aligning elements
Creating flexible Layouts

Example:
container{
    display:flex;
}

3. CSS Grid
I was also introduced to CSS Grid 

Grid is used to create layouts using rows and 
columns.

Example:
.container{
    display:grid;
}
